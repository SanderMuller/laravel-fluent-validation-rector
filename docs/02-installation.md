# Installation

```bash
composer require --dev sandermuller/laravel-fluent-validation-rector
```

**Requirements:** PHP 8.3+, Rector 2.5+, and [`sandermuller/laravel-fluent-validation`](https://github.com/sandermuller/laravel-fluent-validation) ^1.32.0.

On an older fluent-validation, pin the rector to match:

| fluent-validation | Pin rector to |
|---|---|
| 1.17 – 1.19 | `^0.8` |
| 1.20 – 1.26 | `>=1.0 <1.4` |
| 1.27 – 1.31 | `>=1.4 <1.9` |
| 1.32+ | `^1.9` (latest) |
